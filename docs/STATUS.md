# Project Status

更新时间：2026-09-14

## 基本状态

- 状态：MAINTAIN
- 优先级：P3 / 问题驱动
- 当前阶段：第一阶段开发完成，进入维护期

## 一句话目标

保持现有 Android Device Agent 主链路稳定可用；不主动扩功能，后续只有出现明确新需求时再评估新增能力，出现问题则以 Bug 形式修复。

## 当前真实状态

第一阶段开发已经基本告一段落，当前版本已完成核心目标：

- ADB 设备发现与 serial 唯一设备标识
- 远程 shell、点击、滑动、按键、文字输入
- App 启停、设备重启
- 截图与远程投屏
- Windows PySide6 客户端
- 鼠标点击/拖动映射到手机触控
- GitHub Actions 自动测试
- Windows 自动打包
- `v*` tag 自动创建 Release

现阶段不再继续主动增加低延迟视频、鉴权、文件管理、logcat 等候选功能。

## 当前维护策略

1. 不主动增加新功能。
2. 有明确业务需求时，再创建需求 Issue 并重新评估是否进入 ACTIVE。
3. 发现已有功能异常时，以 Bug Issue 形式记录和修复。
4. Bug 修复后继续保持现有自动构建、测试和 Release 流程。

## 下一步唯一动作

> **暂无主动开发动作。保持维护状态，等待真实需求或 Bug。**

## 恢复条件

满足以下任一条件时重新进入开发：

- 出现影响现有功能使用的 Bug；
- 出现明确的新业务需求；
- 需要与其他自动化平台正式集成。

## 恢复上下文提示

重新进入项目时优先查看：

1. `README.md`
2. `docs/STATUS.md`
3. 最近 commits
4. GitHub Issues
5. 最近 Release 与 Actions 构建结果

项目核心约束：所有设备操作必须明确指定 serial，不允许默认选择第一台设备。
